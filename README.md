# Crono Timer — Landing Page

Landing page estática para GitHub Pages.

## Publicar en GitHub Pages
1. Sube todo el contenido de esta carpeta a la raíz de tu repositorio.
2. En GitHub abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, rama `main` y carpeta `/(root)`.
4. Guarda y espera la publicación.

## Archivos importantes
- `index.html`: página principal.
- `assets/crono-timer-app.png`: captura real de Crono Timer.
- `assets/lan-center-background.jpg`: fotografía de fondo del LAN Center.

Los botones de descarga abren la carpeta de Google Drive configurada en el HTML. Los botones de consulta contactan al asesor por WhatsApp. El bloque de tutorial queda preparado para insertar el video de YouTube cuando esté disponible.
